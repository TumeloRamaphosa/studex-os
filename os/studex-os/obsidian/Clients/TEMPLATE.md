# New Client Onboarding Template

Use this for each new client onboarding to StudeX OS.

## Required Information
- [ ] Company name
- [ ] Industry (Retail, Legal, Food, Finance, etc.)
- [ ] Contact person
- [ ] Contact email/phone
- [ ] Primary pain points (3 max)
- [ ] Current software/tools in use
- [ ] Monthly budget

## Onboarding Steps
1. Discovery call — understand pain points
2. Demo — show Super Agents platform
3. Custom agent setup — configure Buzz agent for client
4. Integration — connect their tools (Slack, WhatsApp, etc.)
5. Launch — go live with 1-week sprint
6. Measure — track results, report weekly

## Agent Assignment
Match Buzz agent to industry:
- Retail: RetailBot, SalesCloser
- Legal: ProAssist
- Food: DineAssist
- Finance: FinanceBot
- General: MultiBot
